I'm a solo developer. I design the thing, build the thing, and ship the thing, usually in that order and usually alone.

Most of my work is **Flutter apps** and **React + TypeScript frontends**, plus a long list of single-file HTML tools I use to test ideas fast. I care a lot about how software looks and feels: dark surfaces, glass, tight type, no emoji where an SVG icon belongs.

**Build first. Refine later. Ship to real people.**
